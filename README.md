# Let's Go to Space! 🚀

A simple **HTML/CSS mini project** with a playful space theme.  
Created as part of front‑end practice exercises (Scrimba).

## 🌌 Overview
This project focuses on:
- clean and semantic HTML structure  
- basic CSS styling  
- simple responsive layout  
- no JavaScript included  

It’s a static front‑end exercise designed to practice layout and styling fundamentals.
